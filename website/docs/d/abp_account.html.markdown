# incapsula_abp_account

Looks up the ABP account belonging to the configured API credentials. `account_id` and the data source's own `id` are both the account UUID, so either can be referenced.

## Example Usage

```terraform
# Returns the ABP account ID identified by the provider's API credentials.
data "incapsula_abp_account" "current" {}

resource "incapsula_abp_site" "example" {
  account_id = data.incapsula_abp_account.current.account_id
  name       = "example"
}
```
