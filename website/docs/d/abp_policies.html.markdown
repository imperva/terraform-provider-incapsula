# incapsula_abp_policies

Lists every ABP Policy of an account, ordered by name. Use `incapsula_abp_policy` to look up a single Policy by name or id instead.

## Example Usage

```terraform
# List every policy of the account.
data "incapsula_abp_policies" "all" {
  account_id = var.account_id
}

output "policy_names" {
  value = data.incapsula_abp_policies.all.policies[*].name
}
```
