# incapsula_abp_credential

Provides an ABP Account credential used to authenticate with the Analysis
Host. The secret is generated server-side on creation.
The secret is encrypted by `rsa_key` using OAEP with SHA256 and the label 'abp_credential', and stored
only as `encrypted_secret`; the plaintext `secret` is never written to
state.
Decrypt locally with, for example:
`terraform output -raw encrypted_secret | base64 -d | openssl pkeyutl -decrypt -inkey <your-private-key-file> -pkeyopt rsa_padding_mode:oaep -pkeyopt rsa_oaep_md:sha256 -pkeyopt rsa_oaep_label:$(echo -n 'abp_credential' | xxd -p)`.

`rsa_key` only decides which key the secret in state is encrypted to, so
changing it is an in-place re-encryption of the same secret: the credential on
the server is left untouched. For the same reason `terraform import` is
safe — the imported credential simply has no `encrypted_secret` until the
first apply, which fills it in place without replacing anything.

NOTE: the secret itself cannot be rotated in place. Changing
`account_id` replaces the credential, which generates a new secret. The
Account configuration must be published for the analysis host to begin accepting
a new credential, and you should keep the previous credential alive until that
publish completes (see the API documentation for the recommended rotation
procedure).

## Example Usage

```terraform
resource "incapsula_abp_credential" "my_credential" {
  account_id = var.account_id

  # RSA public key (PEM encoded) used to encrypt the returned secret.
  # Decrypt with, e.g.:
  #   terraform output -raw encrypted_secret | base64 -d \
  #     | openssl pkeyutl -decrypt -inkey <your-private-key-file> \
  #         -pkeyopt rsa_padding_mode:oaep -pkeyopt rsa_oaep_md:sha256 \
  #         -pkeyopt rsa_oaep_label:$(echo -n 'abp_credential' | xxd -p)
  rsa_key = file("${path.module}/public_key.pem")
}

output "encrypted_secret" {
  value = incapsula_abp_credential.my_credential.encrypted_secret
}
```

## Schema

### Required

- `account_id` (String) Account UUID this credential belongs to. Changing it replaces the credential — Terraform deletes the existing one and creates a new one with a new secret — because the API cannot move a credential to another account.
- `rsa_key` (String) A full PEM-encoded RSA public key used for encrypting the secret in state. Must be a `BEGIN PUBLIC KEY` (SPKI) PEM block of at least 3072 bits; other formats and smaller keys are rejected. The secret is encrypted to this key and stored only in `encrypted_secret`, keeping the plaintext out of state. Changing it re-encrypts the same secret in place.

### Read-Only

- `created_at` (String) RFC3339 timestamp at which the credential was created.
- `encrypted_secret` (String) The RSA-encrypted, base64-encoded credential secret
- `id` (String) The ID of this resource.
- `modified_at` (String) RFC3339 timestamp at which the credential was last modified. Always empty: the API does not track modifications of a credential.
