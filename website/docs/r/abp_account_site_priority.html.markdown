# incapsula_abp_account_site_priority

Manages the priority order of Sites within an ABP Account. The first ID in
`site_ids` has the highest priority. The list must include every Site
attached to the Account exactly once — including Sites created outside Terraform.

WARNING: if a Site is missing from `site_ids`, every apply fails with
`Wrong number of site IDs supplied`, which does not say how many Sites
were expected or which ones are missing. A single Site created by anyone — the
UI, another workspace, another module — is enough to block every apply, so write
the list so that it cannot go stale: combine your own Sites with the ones read
from the `incapsula_abp_sites` data source (see the example below)
rather than listing IDs literally.

NOTE: this resource wraps a singleton property of the parent Account.
Destroying it removes the priority from Terraform state but leaves the
server-side order unchanged.

## Example Usage

```terraform
# Defines the order in which an account's Sites are matched. Sites are matched
# top-down.
#
# The list has to contain *every* Site of the account, so list the Sites you
# care about explicitly and append all the others — Sites created in the UI, by
# another workspace, or by another module — from the `incapsula_abp_sites` data
# source. A literal list of IDs breaks as soon as anyone adds a Site.
data "incapsula_abp_sites" "all" {
  account_id = var.account_id
}

locals {
  # The Sites whose relative priority matters, highest priority first.
  prioritized_sites = [
    incapsula_abp_site.sample_site.id,
    incapsula_abp_site.site2.id,
  ]
}

resource "incapsula_abp_account_site_priority" "accprio" {
  account_id = var.account_id
  site_ids = concat(
    local.prioritized_sites,
    [for site in data.incapsula_abp_sites.all.sites : site.id if !contains(local.prioritized_sites, site.id)]
  )
}
```

## Schema

### Required

- `account_id` (String) Account UUID whose Site priority order is being managed. Changing it replaces the resource: Terraform forgets the order of the old Account (leaving it unchanged on the server) and applies this order to the new one.
- `site_ids` (List of String) Site UUIDs in priority order (highest first). Must include every Site attached to the Account exactly once, including Sites created outside Terraform.

### Read-Only

- `id` (String) The ID of this resource.
